# Guia para Contribuir no Projeto Amigurumis Da Iara

Obrigado por colaborar com o projeto! Aqui estão as instruções para você clonar, trabalhar e enviar suas alterações.

---

## Passo 1 – Clonar o Repositório

Abra o terminal e digite:

```bash
git clone https://github.com/anaflaviacorrea/amigurumis-da-iara.git
cd amigurumis-da-iara
```

---

## Passo 2 – Criar uma Branch para suas alterações

Crie uma branch nova para sua tarefa:

```bash
git checkout -b nome-da-sua-branch
```

Exemplo:

```bash
git checkout -b correcoes-layout
```

---

## Passo 3 – Fazer as alterações

Edite os arquivos HTML, CSS e JavaScript no seu editor de preferência.

---

## Passo 4 – Enviar as alterações para o GitHub

Quando terminar, envie seu trabalho:

```bash
git add .
git commit -m "Descrição clara do que foi feito"
git push origin nome-da-sua-branch
```

---

## Passo 5 – Abrir um Pull Request

1. Acesse o repositório no GitHub:  
   https://github.com/anaflaviacorrea/amigurumis-da-iara
2. Clique em **Pull requests** → **New pull request**
3. Compare sua branch com a branch principal (`main` ou `desenvolvimento`)
4. Crie o Pull Request com uma descrição do que foi feito

---

## Passo 6 – Revisão e Merge

- A dona do projeto revisará seu PR.
- Após aprovação, o PR será mesclado na branch principal.

---

## Dicas importantes

- Use mensagens de commit claras e objetivas.
- Nunca envie código direto na branch `main` sem PR.
- Se precisar de ajuda, entre em contato!

---

Muito obrigado por ajudar a manter o projeto Amigurumis Da Iara lindo e funcional! 💜
